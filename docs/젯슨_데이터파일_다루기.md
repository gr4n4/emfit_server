# 젯슨 데이터 파일(jsonl) 보기 · 지우기

> 센서가 보낸 원본 기록을 확인하거나 정리할 때 쓰는 명령 모음.
> 모두 **SSH 접속 후** 실행한다: `ssh operator@jetson-host`

## 파일이 어디에 있나

| 파일 | 무엇이 들어가나 |
|---|---|
| `~/emfit_server/emfit_data.jsonl` | Emfit 침대 센서 (가장 큼, 86MB+) |
| `~/emfit_server/radar_data.jsonl` | AI Radar (라닉스) |
| `~/emfit_server/mckare_data.jsonl` | McKare |
| `~/emfit_server/fsr_data.jsonl` | 돌봄기기 사용감지 (ESP32) |

```bash
cd ~/emfit_server
ls -lh *.jsonl          # 파일 목록 + 크기
```

## 보기

```bash
# 마지막 5줄
tail -5 fsr_data.jsonl

# 실시간으로 지켜보기 (센서 테스트할 때 유용, Ctrl+C 로 종료)
tail -f fsr_data.jsonl

# 총 몇 줄인지
wc -l fsr_data.jsonl

# 특정 기기 것만
grep B1C2D3E4F5A6 fsr_data.jsonl | tail -5

# 마지막 줄을 보기 좋게 (줄바꿈·들여쓰기)
tail -1 fsr_data.jsonl | python3 -m json.tool

# 오늘 들어온 것만
grep "$(date +%Y-%m-%d)" fsr_data.jsonl | wc -l
```

> **SSH 없이 보려면** — 대시보드에서 `/dashboard/raw` 로 들어가면
> 마지막 수신 기록과 전체 줄 수를 웹에서 볼 수 있다 (관리자 로그인 필요).

## 지우기

⚠️ **원본 데이터다. 지우면 되돌릴 수 없다.** 아래 순서를 지키자.

### 특정 기기·패턴만 지우기 (가장 흔한 경우)

```bash
cd ~/emfit_server

# 1) 먼저 몇 건이 지워질지 확인 — 이 단계는 아무것도 안 지운다
grep -c "지울패턴" fsr_data.jsonl
grep "지울패턴" fsr_data.jsonl | head -3      # 진짜 그 줄이 맞는지 눈으로 확인

# 2) 백업
cp fsr_data.jsonl fsr_data.jsonl.bak

# 3) 삭제
sed -i '/지울패턴/d' fsr_data.jsonl

# 4) 확인 — 0 이 나오면 성공
grep -c "지울패턴" fsr_data.jsonl

# 5) 서버 재시작 (아래 '왜 재시작이 필요한가' 참고)
sudo systemctl restart emfit
```

> 패턴이 너무 짧으면 엉뚱한 줄까지 지워진다. 1번에서 반드시 눈으로 확인할 것.
> 여러 패턴을 한 번에: `sed -i '/패턴A\|패턴B/d' 파일`

### 파일 전체 비우기

```bash
cp fsr_data.jsonl fsr_data.jsonl.bak    # 백업
> fsr_data.jsonl                         # 내용만 비움 (파일은 남김)
sudo systemctl restart emfit
```

### 파일 자체를 없애기

```bash
rm fsr_data.jsonl
sudo systemctl restart emfit
```
> 없어도 서버는 정상 동작한다. 다음 수신 때 자동으로 다시 만들어진다.

---

## 왜 재시작이 필요한가

서버는 속도를 위해 파일 내용을 메모리에 캐시해 둔다.
줄을 지워도 **화면에는 지운 기기가 한동안 그대로 남아 있을 수 있다.**
재시작하면 캐시가 비워지면서 정리된다.

⚠️ 재시작 후에는 큰 로그를 다시 읽느라 몇 분간 **"점검 중"** 화면이 뜬다.
그동안에도 센서 수신은 계속되므로 데이터는 잃지 않는다.

## 기기 목록에서도 지워야 할 때

jsonl 에서 줄을 지워도 **대시보드 카드는 남는다.**
기기 등록은 `assignments.json` 이라는 별도 파일에 있기 때문이다.

```bash
cd ~/emfit_server
cp assignments.json assignments.json.bak

python3 - <<'PY'
import json
p = '/opt/monitoring_server/assignments.json'
SN = '여기에_지울_기기_SN'          # 예: 'CONNECTIVITY-TEST'
a = json.load(open(p, encoding='utf-8'))
n = [x for x in a if x.get('sn') != SN]
json.dump(n, open(p, 'w', encoding='utf-8'), ensure_ascii=False, indent=2)
print(f'제거 {len(a)-len(n)}건 / 남은 배정 {len(n)}건')
PY

sudo systemctl restart emfit
```

> 이름만 바꾸고 싶다면 지우지 말고 대시보드 `/devices` 에서 수정하는 편이 안전하다.

## 되돌리기

백업을 떠뒀다면:

```bash
cd ~/emfit_server
cp fsr_data.jsonl.bak fsr_data.jsonl
cp assignments.json.bak assignments.json
sudo systemctl restart emfit
```

백업 파일 정리는 확인이 끝난 뒤에:
```bash
rm ~/emfit_server/*.bak
```
